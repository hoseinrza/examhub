=== نام افزونه ===
ExamHub

== توضیحات ==
سامانه مدیریت بانک آزمون‌های نهایی برای ثبت، دسته‌بندی و مدیریت آزمون‌ها، فایل سوالات و پاسخنامه، جستجو و فیلتر پیشرفته و نمایش از طریق ویجت‌های المنتور.

== امکانات اصلی ==
* داشبورد مدیریت فارسی برای تیم محتوا
* مدیریت آزمون‌ها و وضعیت انتشار
* مدیریت مقطع، پایه، رشته، درس، سال، نوبت و نوع آزمون
* ثبت فایل سوالات و پاسخنامه از کتابخانه رسانه یا آدرس خارجی
* علامت‌گذاری آزمون‌های ویژه و نمایش آمار دانلود
* جستجو و فیلتر پیشرفته و اتصال به المنتور

== نصب ==
۱. پوشه افزونه را در مسیر /wp-content/plugins/ قرار دهید.
۲. از بخش افزونه‌های وردپرس، ExamHub را فعال کنید.
۳. از منوی «آزمون‌ها» وارد داشبورد و مدیریت محتوای افزونه شوید.

== تغییرات نسخه ۱.۲.۰ ==
* اضافه شدن داشبورد مدیریتی فارسی و حرفه‌ای
* یکپارچه‌سازی برچسب‌های مدیریت آزمون‌ها و دسته‌بندی‌ها به زبان فارسی
* بهبود ظاهر صفحات مدیریت، فرم‌ها و جدول آزمون‌ها
* حفظ کامل ساختار داده‌ها و عملکرد موجود
* بهبود پیام‌های خطای سمت کاربر به زبان فارسی
