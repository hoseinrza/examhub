## CSS Selector Syntax Tips

All selectors follow this pattern:
```css
body.page-id-2918.dark-mode .component-class { }
```

**Key points:**
- ✅ Always start with `body.page-id-2918.dark-mode`
- ✅ Space between compound selectors
- ✅ Use class selectors (`.`) not ID selectors
- ✅ Consistent specificity across all rules
- ✅ No nesting (plain CSS, not SCSS)
